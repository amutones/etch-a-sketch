# Etch-A-Sketch

A simple browser-based Etch-A-Sketch clone built with HTML, CSS, and vanilla JavaScript.

## Features
- Draw on a grid with your mouse
- Reset / clear the board
- Adjustable grid size with limits
- Simple responsive layout

## Tech Stack
- HTML
- CSS
- JavaScript (DOM manipulation, event handling)

## How to Run
https://amutones.github.io/etch-a-sketch/
OR
Clone the repo:
   git clone git@github.com:amutones/etch-a-sketch.git
   Open `index.html` in your browser.
